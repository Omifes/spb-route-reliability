# Web Service for Assessing Public Transport Route Reliability in St. Petersburg

Веб-сервис для оценки и анализа надежности маршрутов общественного транспорта Санкт-Петербурга.

## Стек технологий

- **Backend:** Python, FastAPI, SQLAlchemy / asyncpg
- **Database:** PostgreSQL
- **Frontend:** React, TypeScript
